# Постоянные VBO и GPU-анимация — 15 октября 2026

## Реализация

- Геометрия geo-модели запекается в один `VertexBuffer.Usage.STATIC` при первом
  показе и переиспользуется всеми экземплярами той же модели и её проходами.
  Отдельные фиксированные повороты кубов запекаются в ближайшую кость.
- Вершины содержат индекс кости. Положение и нормали преобразуются в вершинном
  шейдере; матрицы до 64 костей передаются через UBO размером 8 КиБ. Неподходящие будущие модели
  автоматически используют прежний рендер.
- Кадр больше не пересчитывает и не отправляет все вершины модели с CPU.
  Кэшируются список анимируемых частей и массивы матриц. На один экземпляр
  модели приходится один draw call на проход, а не отдельный вызов для каждой кости.
- Прозрачные грани сортируются по обновлённым центрам с учётом анимации. Для этого
  обновляется только индексный буфер; вершины остаются на GPU. Экземпляры внутри
  одного прозрачного пакета сортируются по расстоянию до начала их позы.
- Команды исполняются на исходной границе `BufferSource.endBatch(RenderType)`.
  Сохраняются тип прохода, текстуры, освещение, overlay, туман и свечение.
  Кости и их видимость захватываются до следующего изменения общей модели.
- GPU-ресурсы освобождаются и лениво создаются заново при перезагрузке шейдеров,
  а также освобождаются до уничтожения GL-контекста при завершении игры.
  Клиентский миксин не загружается выделенным сервером.

Охват: geo-модели техники, дронов, ракет, загруженных дронов на направляющих
и опознавательных знаков. Небольшие модели старых ванильных слоёв остаются
на исходном пути. С Oculus/Iris и нестандартными outline/foil-обёртками новый
рендер выключается для совместимости; ускорение VBO в этих случаях не заявляется.

## Реальные графические проверки

Команда: `./gradlew --offline -PgpuSmokeTest runClient` с Java 17.
Запускался отдельный клиент с настоящим OpenGL-контекстом на этом Mac,
без входа в пользовательский мир. Результат: `GPU_CHECKS_PASSED`.

Проверены «Град», «Искандер», ЗРК, FPV и ракета «Града»: повороты башни,
подъём пакета и стрелы, скрытая ракета и масштабирование штока опоры.
Изображения стандартного и GPU-рендера сравнены попиксельно для проходов
CUTOUT и TRANSLUCENT; отдельно проверено свечение «Града».
После настоящей перезагрузки ресурсов все сравнения выполнены повторно.
В итоговом прогоне не было пикселей с отклонением цветового канала больше 12/255;
среднее отклонение канала во всех сценариях меньше 0.006/255.

Проверка повторного использования: при отрисовке множества экземпляров счётчик
загрузок геометрии не растёт. До перезагрузки были созданы ровно пять VBO
для пяти проверяемых корней моделей.

Микротест: 32 копии «Града» в одном offscreen-кадре 256×256, медиана пяти
повторов после прогрева, включая отрисовку и считывание изображения:

- CUTOUT: CPU 7.363 мс → VBO 2.130 мс, примерно в 3.5 раза быстрее.
- TRANSLUCENT: CPU 27.918 мс → VBO 12.808 мс, примерно в 2.2 раза быстрее.

Это результат конкретного теста рендера, **не замер FPS полноценного мира**.
Время включает работу драйвера и GPU; оно не является чистым профилем CPU.
Нагрузка от сущностей, чанков, взрывов и ИИ этим изменением не устраняется.

Графические журналы: `gpu-client-checks.log`, `gpu-checks/results.txt`.
В `gpu-checks` сохранены пары CPU/GPU PNG. Они считываются из framebuffer
в OpenGL-ориентации по Y и служат для сравнения, а не скриншотами игрового окна.

## Финальные проверки

- `./gradlew --offline clean build runGameTestServer`: BUILD SUCCESSFUL,
  все 12 серверных GameTests прошли. Журнал: `verification-gpu-final.log`.
- modkit: 244 JSON, ошибок синтаксиса и проверяемых ссылок нет.
- Проверен готовый JAR: присутствуют GeoGpu, клиентский BufferSourceMixin,
  его remap-запись и три пары shader JSON/VSH; тестовые классы отсутствуют.
- JAR: `build/libs/harddayz-forge-1.20.1-0.3.6.jar`.

Не измерялись FPS в живом мире с большим количеством разнообразной техники,
работа с установленными шейдерпаками и сортировка взаимно пересекающихся
полупрозрачных моделей. Межмодельная прозрачность теперь сортируется по моделям,
а не одним глобальным списком всех граней. Для проверенных одиночных моделей
сравнение изображений прошло.
