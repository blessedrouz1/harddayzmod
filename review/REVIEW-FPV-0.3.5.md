# Подключение FPV и виньетка — 15 октября 2026

Исправлены два клиентских пути, мешавших подключению:

- `ClientGuns.onUse` отменял ПКМ при оружии или дальномере в руке до отправки
  взаимодействия с дроном на сервер. Теперь при наведении на пилотируемый
  квадрокоптер взаимодействие пропускается. Сервер продолжает проверять
  владельца, заряд и занятость дрона.
- `DronePilot.ignoreUntil` использовал tickCount предыдущего игрока и переживал
  смену мира. Новый игрок начинал счётчик с нуля и мог долго не проходить проверку
  задержки подключения. Теперь при смене уровня или объекта игрока очищается
  состояние камеры, ввода, заморозки тела и задержки; старому игроку возвращается
  исходный ввод. Проверка выполняется и в клиентском тике, и перед подключением.

Добавлена чёрная виньетка только при пилотировании FPV. Маска имеет прозрачный
центр и плавное нарастание непрозрачности к краям. HUD и прицел рисуются поверх.
При выходе из режима пилотирования маска перестаёт отображаться.

Проверки:

- Java 17, `./gradlew --offline clean build runGameTestServer`: BUILD SUCCESSFUL,
  все 12 существующих серверных тестов прошли (`verification-fpv.log`).
- Проверено включение RGBA-маски в JAR, прозрачность центра и непрозрачность углов.
- Превью маски просмотрено: `fpv-vignette-preview.png`.
- modkit: 241 JSON, ошибок синтаксиса и проверяемых ссылок нет.

Серверные тесты не проверяют клиентские события мыши, переход между мирами
и отрисовку HUD. Эти клиентские сценарии проверены по коду; проверка в игре
не выполнялась. Для применения изменений в уже открытом Minecraft нужен
перезапуск клиента.

JAR: `build/libs/harddayz-forge-1.20.1-0.3.5.jar`.
