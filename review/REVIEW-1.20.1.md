# Ревью HardDayz для Minecraft 1.20.1 — 15 октября 2026

Проверен проект `harddayzmod-main`, Forge 47.4.10, Java 17, official mappings 1.20.1.
Основной охват: сетевые декодеры, команды оружия и дронов, жизненный цикл ранения,
загрузка на сервере, метаданные совместимости и ресурсы. Это не полная проверка
всех игровых механик. Оригинал 26.3 не изменялся.

## Исправления

1. **P1 — некорректное движение дрона** (`Drone.pilotMove`). Проверка расстояния
   не отбрасывала NaN: сравнение `NaN > 12` ложно. Теперь все координаты и углы
   проверяются на конечность до трассировки, изменения скорости и позиции.
   Сохранены проверка пилота и ограничение скачка в 12 блоков.
2. **P2 — неверное чтение списков из пакетов** (`Net.readList/readInts`). Обрезание
   объявленного размера оставляло лишние элементы в буфере: например, поле `open`
   могло читаться из содержимого списка. Отрицательные размеры вызывали ошибку
   выделения списка. Теперь размеры вне допустимых границ отклоняются явной
   ошибкой декодирования; координаты журнала должны идти полными тройками.
   Формат корректных пакетов не изменён.
3. **P2 — стрельба в недоступных состояниях** (`GunItem`, `JavelinItem`). Подствольник
   обходил проверку ранения, присутствующую в обработчике обычного выстрела.
   Добавлена общая проверка: игрок жив, не наблюдатель, не ранен и не сидит
   в транспорте. Она применяется к обычному оружию, подствольнику и Javelin.
4. **P2 — сохранение медицинского состояния после смерти** (`Medic`). После
   добивания оставались прогресс реанимации, счётчик сдачи и принудительная поза.
   Теперь состояние очищается при завершении ранения, а новая травма начинается
   без предыдущего прогресса. Статические таблицы очищаются при остановке сервера,
   чтобы не переносить состояние между одиночными мирами в одном процессе.
5. **P2 — Javelin игнорировал задержку перезарядки** (`JavelinItem.shoot`). Его
   собственный обработчик обходил проверку времени следующего выстрела. Теперь
   пуск запрещён до истечения записанного `next`, как у базового оружия.
6. Метаданные ограничены Minecraft 1.20.1 и Forge [47.4.10,48); README исправлен
   с версии оригинала 26.3 на фактическую версию порта.

## Проверки

- `./gradlew --offline clean build runGameTestServer` с Java 17: BUILD SUCCESSFUL.
- Серверная загрузка Forge и миксинов: успешна в среде GameTest.
- Пять GameTests: все прошли. Проверяются неверные и корректные сетевые списки,
  NaN/Infinity и обычное движение дрона, очистка состояния ранения после добивания,
  запрет стрельбы раненому/наблюдателю, задержка Javelin при наличии цели.
- Проверка ресурсов modkit: 276 JSON, ошибок синтаксиса и прямых ссылок на модели
  и текстуры нет. Проверка не охватывает все схемы рецептов и динамические ссылки.
- Финальный JAR содержит refmap; тестовые классы и тестовая структура в него
  не включены.
- Полный журнал успешной сборки и тестов: `verification.log`.

JAR: `build/libs/harddayz-forge-1.20.1-0.2.1.jar`.

## Ограничения

Клиент игры и сеанс с реальными игроками не запускались. Отрисовка, управление
дронами на больших расстояниях, сетевые задержки и совместимость с другими модами
требуют проверки в игре. GameTests проверяют обработчики и состояние на сервере,
но не заменяют полноценный сетевой сеанс. Существующие предупреждения deprecated
API остаются. Повторная сборка без clean на промежуточных файлах дала ошибку
Duplicate entries в reobfJar; чистая сборка завершилась успешно. Для воспроизведения
результата используйте указанную команду с clean.
