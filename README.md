# HardDayz

Мод на Minecraft про современную войну. Делаем для игры с друзьями.

Тут есть ракетная техника (Град, Искандер, HIMARS, ТОС), ПВО (ЗРК, С-400, Patriot, NASAMS, пулемёты), дроны (Шахеды, FPV, разведчики, Ланцет, перехватчики), Bradley, пикапы, миномёт, стрелковое оружие с обвесами, инженерка для обустройства позиций и медицина.

У техники есть хп, топливо, боекомплект, и если её подбить с полным бк, бахнет сильно.

Есть режим войны: команды, штабы, магазин с доставкой, точки захвата, сирены и радары. Второй вариант: режим жизней, где у каждой команды общий запас жизней и кто первый всё потратит, тот проиграл.

Версия Minecraft 1.20.1, Forge 47.4.10 или новее в ветке 47, Java 17.

Проверки: `./gradlew clean build runGameTestServer` с Java 17. Серверные
регрессионные тесты находятся в `src/test`, запускаются в `build/gametest-run`
и не включаются в распространяемый JAR. Результаты ревью: `review/REVIEW-1.20.1.md`.

В 0.3.6 геометрия geo-моделей техники, дронов и ракет хранится в общих постоянных
VBO. Кости анимируются на GPU; для прозрачности обновляются индексы граней,
а не вершины. С Oculus/Iris и нестандартными обёртками отрисовки используется
совместимый путь через собственный обход костей: Oculus не подменяет геометрию наших граней.

Графическая проверка: `./gradlew --offline -PgpuSmokeTest runClient`. Она запускает
отдельный клиент без входа в мир, сравнивает CPU/GPU-изображения, проверяет
повторное использование VBO и перезагрузку ресурсов, затем закрывается.
Результаты: `review/gpu-checks/results.txt`. Подробности: `review/REVIEW-GPU-0.3.6.md`.

В 0.3.7 подъёмники 12 ракетных установок имеют жёсткий корпус и два выдвижных
звена с перекрытием. Верхний шарнир задан костью `ram0_mount` / `eram0_mount`;
шток следует за ней после поворота башни и подъёма направляющих.
После повторного экспорта старых geo-моделей: `python3 art/vehicles/upgrade_hydraulics.py`.

Oculus установлен для тестового клиента: `./gradlew --offline -Poculus runClient`
(или `launch-minecraft.command`). Используются Oculus 1.8.0 и Embeddium 0.3.31
для Forge 1.20.1; Gradle подключает их с преобразованием имён для среды разработки.
Оригинальные JAR для обычного Forge находятся в `runtime-mods/`; их не нужно
дублировать в `run/mods`, иначе получится повторная загрузка тех же модов.

Проверка моделей с Oculus: `./gradlew --offline -Poculus -PmodelSmokeTest runClient`.
Результаты `review/model-checks/results.txt`, изображения рядом. Проверяются
1092 позы подъёмников, видимость шести моделей и перезагрузка ресурсов.
Проверка выполнена с Oculus и Embeddium без выбранного стороннего шейдерпака.

В 0.3.8 прямоугольная виньетка камеры идёт от краёв экрана на всех дронах.
«Шахед-238» и «Герань-5» оставляют ограниченный по числу частиц след из сопла:
короткий факел и дым вдоль пройденного пути. Стоянка и скачки позиции следа не создают.
Дым, пыль и огонь используют плотный стандартный проход частиц; вспышки и свечение
сохраняют смешивание. Затухание начинается в конце жизни частиц.
Графическая проверка: `./gradlew --offline -Poculus -PdroneFxSmokeTest runClient`.
Результаты и изображения: `review/drone-fx-checks/`.
