# HardDayz

Мод на Minecraft про современную войну. Делаем для игры с друзьями.

Тут есть ракетная техника (Град, Искандер, HIMARS, ТОС), ПВО (ЗРК, С-400, Patriot, NASAMS, пулемёты), дроны (Шахеды, FPV, разведчики, Ланцет, перехватчики), танки, БМП, пикапы, вертолёты, миномёт, стрелковое оружие с обвесами, инженерка для обустройства позиций и медицина.

Техникой управляешь сам: ездишь, наводишь пусковую через пульт, ведёшь дрон с камеры. У техники есть хп, топливо, боекомплект, и если её подбить с полным бк — бахнет сильно.

Есть режим войны: команды, штабы, магазин с доставкой, точки захвата, сирены и радары. Второй вариант — режим жизней, где у каждой команды общий запас жизней и кто первый всё потратит, тот проиграл.

Версия Minecraft 26.3, Forge 66. Скачать готовый мод можно во вкладке Releases.
